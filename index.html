02 / PANORAMA

Qui ha presentat més PNL?

PNL d’autoria exclusiva d’un grup: Ple + comissió. No inclou les de coautoria ni les procedents del Senat.

COM LLEGIR-HO

Més iniciatives no vol dir automàticament més resultats.

El nombre de PNL depèn de l’estratègia parlamentària, la dimensió del grup i el tipus de proposta. Tampoc no és una mesura de qualitat o d’impacte real.

El Grup Mixt agrupa formacions diferents; les seves xifres no s’han d’atribuir a un sol partit.

03 / TRANSPARÈNCIA

Què sabem, i què no?

01

Proposta registrada

Documenta què ha defensat públicament un grup, en una data i un context concrets. No demostra què faria necessàriament si governàs.

02

Aprovació ≠ llei

Les PNL no creen normes jurídicament vinculants. Una proposta rebutjada pot ser molt explícita; una caducada no és una proposta rebutjada.

03

Mostra no representativa

Els exemples d’aquesta maqueta estan triats per mostrar el funcionament. No es poden usar per deduir les prioritats temàtiques globals de cada grup.

04

Comprovació directa

Cada fitxa enllaça a un expedient oficial. Una futura versió incorporarà el text dispositiu íntegre, les esmenes i el vot detallat.
